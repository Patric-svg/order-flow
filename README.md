# Order Flow

A frontend learning project exploring order-flow concepts and market-structure presentation.

## Run locally

```bash
git clone https://github.com/Patric-svg/order-flow.git
cd order-flow
python -m http.server 8000
```

Open <http://localhost:8000> and inspect the `forex_course` directory for the project content.

## Scope

This repository is educational material. It does not provide financial advice or guarantee trading results. Validate any market claim against independent sources and use paper trading for experiments.
